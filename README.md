# 🏥 Site Institucional - Clínica de Reabilitação Raio de Sol

> Status do Projeto: Em Desenvolvimento / Ajustes Finais 🚧

## 📋 Sobre o Projeto
O projeto **Raio de Sol** é um site institucional desenvolvido para uma clínica de reabilitação pública. O objetivo da aplicação é oferecer um canal de comunicação claro e acessível, permitindo que pacientes e familiares encontrem facilmente informações sobre os serviços oferecidos, estrutura de atendimento e canais de contato.

- 🔗 **Acesse o projeto online (GitHub Pages):** [Clique aqui para visualizar o site](https://matheus-soares-prog.github.io/clinica-raio-de-sol/home.html)

---

## 🚀 Tecnologias Utilizadas
O projeto foi construído utilizando as seguintes tecnologias e conceitos:
- **HTML5:** Estruturação semântica das páginas (uso de tags adequadas para acessibilidade e organização).
- **CSS3:** Estilização visual, escolha de paleta de cores acolhedora e design responsivo.
- **Git & GitHub:** Controle de versão do código-fonte e hospedagem web.

---

## 🎨 Principais Funcionalidades
- **Estruturação Multi-página:** Navegação intuitiva entre as seções de apresentação da clínica, serviços e contato.
- **Layout Responsivo:** Adaptado para visualização em diferentes tamanhos de tela (computadores, tablets e celulares).
- **Acessibilidade e Foco Social:** Conteúdo estruturado para o contexto de uma clínica pública de reabilitação.
